Con 4 cortes, la media histórica empata con Ridge (+0,09 pp, IC [−0,56; +0,73]) y supera a Gradient Boosting. Al triplicar los datos de entrenamiento en días laborales, el orden se invierte. Ambas conclusiones salen del mismo protocolo de origen móvil.

Es una selección por segmento, no una contradicción: el modelo complejo gana donde tiene datos suficientes. Para sábado y domingo no hay libros 2023, así que seguimos con el modelo simple.
